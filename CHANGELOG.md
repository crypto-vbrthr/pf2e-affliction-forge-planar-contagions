# Changelog

## 0.1.0

- Initial Planar Contagions library release.
- Added 32 original staged afflictions from levels 0–20.
- Added extraplanar creature, origin, theme, and delivery coverage for Creature Forge matching.
- Added diseases, natural/supernatural poisons, and planar curses.
- Added semantic Creature Forge tags using contract 1.0.0.
- Added DE/EN localization.
- Added advanced stage mechanics using the existing Affliction Forge runtime.
- Added Foundry 14-safe managed compendium synchronization.
- Added schema, localization, semantic-tag, portability, and runtime smoke tests.
